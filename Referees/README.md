# Referees

Analyses of NHL referee penalty-call tendencies relative to team and league averages. Currently publishes as short-form X content; a longer-form Substack post is planned but not yet published.

## What this analyzes

Each referee has tendencies — types of penalties they call more or less often than the league average, and how their call distribution shifts depending on which team is involved. The analyses in this folder quantify those tendencies using NHL play-by-play data over multiple seasons.

Typical analyses look at:

- Penalty type distribution per referee vs league average
- Per-game penalty rates per referee
- Referee-team interaction effects (does Ref X call more penalties against Team Y than other refs do?)
- Pre-game scouting summaries for upcoming games

## What's in this folder

```
Ref Cache/        Cached NHL API responses (gitignored — see below)
Penalties/        Per-game and pooled penalty data
Scripts/          Production scripts for ref analysis
```

## Ref Cache — note on regeneration

`Ref Cache/` holds approximately 7,872 cached NHL API responses (per-game play-by-play and referee assignment JSONs across multiple seasons). This cache is gitignored — it does not ship with the repo. Cache regeneration is required before any ref analysis can run on a fresh clone.

The cache is regenerated by running `pull_all_teams_penalties.py` (and supporting scripts in this folder). Cache repopulation hits the NHL API once per game and may take significant time depending on how many games need pulling. The cache is stable across sessions once populated.

If you encounter a fresh clone and want to run ref analyses, expect to:

1. Run the data-pull scripts to populate `Ref Cache/`
2. Run the per-game penalty extraction scripts
3. Run the per-referee aggregation and tendency analyses

Detailed run order is documented in script headers within `Scripts/`.
