# NFI-Score — score-state adjustment layer

**Source file:** `Data/nhl_shot_events.csv` — the master shot events file used by the existing two-way pipeline. **Season window:** 6 seasons, 2020-21 through 2025-26 regular season, regulation only. **Player universe:** 379 forwards from `NFI/Output/player_two_way_split.csv` (the existing two-way composite's eligibility filter: pooled ES TOI ≥ 1500 min and 2025-26 GP ≥ 20). **Filter mirroring:** ES (situation_code skater parity), regulation (period 1–3), regular season (`game_type=='regular'`), Fenwick events (shot-on-goal, missed-shot, goal), zone in {CNFI, MNFI}, empty-net excluded — replicated from `NFI/scripts/player_two_way_split.py`.

**Naming convention.** States: `Down2 / Down1 / Tied / Up1 / Up2` (shooter's team perspective, diff ≤ −2 / −1 / 0 / +1 / ≥ +2). Metric types: `-Off` (CNFI+MNFI Fenwick events FOR per 60 on-ice), `-Def` (events AGAINST per 60), `-Net` (Off − Def). Output families: raw per-state `NFI-Score-{State}-{Type}` (15 cols), player-own all-sit baseline `NFI-Score-RawAllSit-{Type}` (3 cols, weighted by player's per-state TOI %), score-adjusted `NFI-Score-A-{Type}` (3 cols, weighted by league per-state TOI %), and deltas `NFI-Score-D-{State}-{Type}` (15 cols, raw minus RawAllSit).

**Output files.** `nfi_score_state_lookup.csv` (Step 1 — per-event score state, 921,874 rows). `per_state_toi.csv` (Step 2 — per-player ES TOI in each of the 5 states, 379 rows). `nfi_score_player_rates.csv` (Step 3 — wide table, 379 rows × 47 cols). `nfi_score_summary_ranking.csv` (Step 3 — headline ranking sorted by `NFI-Score-A-Net − NFI-Score-RawAllSit-Net` desc). `window_gap_report.csv` (Step 0 / Step 3 — diagnostic notes on the 5-vs-6 season gap and cross-check vs published two-way per-60 rates).
